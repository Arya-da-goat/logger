DISCORD IP LOGGER - ONE CLICK SETUP

1. Upload all files to any PHP hosting
2. Run database.sql in phpMyAdmin
3. Update config.php with your database details
4. Use index.php URL as image source in Discord
5. Check ip_log.txt for captured data

TIPS:
- Use URL shorteners to hide the real link
- Make the image seem legitimate (avatar, meme, etc.)
